# EMULATE

## Name
   emulate [0] -- emulate another player and governor (deity only)

## Syntax
   emulate <player> <governor>

## Description
   Switches your current session to act as `<player>` and `<governor>`
(`governor >= 1`, must be an active governor on that race). Active deity (`god`)
privileges are cleared for the session so subsequent commands execute under
normal mortal visibility, ownership, and action point rules.
