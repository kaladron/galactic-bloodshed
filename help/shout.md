# SHOUT

## Name
   shout [0] -- send an administrative broadcast to all sessions (deity only)

## Syntax
   shout <message>
   !<message>

## Description
   Sends an administrative message from a deity to every connected player and
governor session in the game. Unlike `broadcast`, `shout` bypasses player `gag`
toggles so critical server announcements are always delivered.
